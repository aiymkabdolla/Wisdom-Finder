# Мақалмен айт

**Мақалмен айт** — қазақ халқының мақал-мәтелдерін күнделікті өмірмен байланыстыратын цифрлық веб-жоба.

## Жоба идеясы

Пайдаланушы өзінің жағдайын немесе ойын қазақ тілінде сипаттайды. Сайт сол жағдайға сәйкес үш қазақ мақал-мәтелін ұсынады және олардың мағынасын түсіндіреді.

## Мүмкіндіктері

- Жағдайға сәйкес мақал-мәтелдерді іздеу
- Әр мақалдың мағынасын түсіндіру
- Ұнаған мақалдарды таңдаулыларға сақтау
- Іздеу тарихын сақтау
- Мақалдарды көшіру
- Қазақ тіліндегі интерфейс
- Телефон мен компьютерге бейімделген дизайн

## Қолданылған технологиялар

- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub Pages

## Қалай жұмыс істейді?

Қазіргі нұсқада мақалдарды таңдау JavaScript арқылы жүзеге асады. Жүйе пайдаланушы енгізген мәтіндегі кілт сөздерді мақалдар базасымен салыстырады.

## Автор

Мақалмен айт — қазақ тіліндегі цифрлық жоба.
